# Reference material

## The acid test line

`acid_test_pattern16.txt` and `acid_test_settings.txt` are the line and knob
settings used for the filter comparison renders, so the same thing can be
played on the CHOMPI (and set up on a TB-303) to compare.

To load them, with the card in a computer:

1. Append `acid_test_pattern16.txt` to the end of `/X0X/patterns.txt`. It
   replaces pattern 16 only; your other patterns are untouched.
2. Append `acid_test_settings.txt` to the end of `/X0X/current.txt` (back it
   up first if you want your knob settings back: these replace them). It also
   selects pattern 16.
3. Power on and press PLAY.

The settings: cutoff 22 %, resonance full, env mod 65 %, decay 30 %, accent
75 %, tempo 125 BPM, no effects.
